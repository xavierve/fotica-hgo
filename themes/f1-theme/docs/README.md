# F1 Theme

F1 Theme es un tema Hugo ligero para webs corporativas y sanitarias locales.

Objetivo de esta versión v0.1: crear una base funcional para Ópticas Fausto sin depender de WordPress, page builders ni frameworks CSS pesados.

## Activación

En `hugo.toml`:

```toml
theme = 'f1-theme'
```

## Carpetas principales

- `content/`: páginas Markdown del sitio.
- `data/site.yaml`: datos globales de negocio, header y footer.
- `themes/f1-theme/layouts/`: plantillas Hugo.
- `themes/f1-theme/layouts/partials/`: bloques reutilizables.
- `themes/f1-theme/assets/css/`: CSS del tema.
- `themes/f1-theme/docs/`: documentación mínima funcional.

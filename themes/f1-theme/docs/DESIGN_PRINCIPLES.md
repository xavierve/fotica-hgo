# F1 Theme · Design Principles

- Mobile first.
- HTML semántico.
- CSS Vanilla con variables en `:root`.
- Sin Bootstrap, Tailwind ni jQuery.
- SEO first: title, description, canonical, OG y Schema desde el contenido.
- Accesibilidad razonable desde v0.1: landmarks, alt text, navegación clara y estructura de encabezados.
- Contenido separado del tema.
- Los bloques deben tener una responsabilidad clara.
- Los datos globales viven en `data/site.yaml`.
- Las páginas se construyen desde front matter + `sections`.
- El tema debe ser útil antes de ser perfecto.

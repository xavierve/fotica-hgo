{{- /* partials/hero-config.html Resuelve, a partir del front matter `hero:` de una pagina, QUE layout se renderiza y con QUE imagen. Lo usan hero.html (markup) y header-meta.html (preload LCP): una sola fuente de verdad, para que el preload nunca apunte a una imagen que el hero no usa. Entrada: la pagina (.). Sin `hero:` devuelve layout "" (y sin src). hero.layout: (ausente) | stacked -> foto a sangre arriba, bloque de color debajo. DEFECTO. overlay -> texto sobre la imagen (solo desde 821px; en movil se apila igualmente: nunca hay texto sobre foto en movil). split -> texto + figura en dos columnas (Home). Sin imagen utilizable el hero degrada a "plain" (solo texto). Origen de la imagen: split -> `image`. stacked/overlay -> `bg`, y si falta, `image` (una pagina que declare image sin layout sigue teniendo foto). Devuelve dict: layout, src, mobile ("" si no hay bgMobile), sizes. sizes: el atributo sizes de la imagen (y del preload), calculado UNA vez para que markup y preload nunca diverjan. En stacked la banda tiene tope de ancho (--hero-band-max en critical.css): por encima de eso la foto no crece, asi que el navegador no debe pedir un archivo mayor. $bandMax y el token CSS van a la vez. */ -}} {{- $h := .Params.hero | default dict -}} {{- $layout := $h.layout | default "stacked" -}} {{- $src := "" -}} {{- if eq $layout "split" -}} {{- $src = $h.image | default "" -}} {{- else -}} {{- $src = $h.bg | default ($h.image | default "") -}} {{- end -}} {{- $mobile := "" -}} {{- if ne $layout "split" -}}{{- $mobile = $h.bgMobile | default "" -}}{{- end -}} {{- $bandMax := 1440 -}}{{- /* = --hero-band-max */ -}} {{- $sizes := "100vw" -}} {{- if eq $layout "stacked" -}}{{- $sizes = printf "(min-width:%dpx) %dpx, 100vw" $bandMax $bandMax -}}{{- end -}} {{- if eq $layout "split" -}}{{- $sizes = "(min-width:821px) 45vw, 100vw" -}}{{- end -}} {{- if not $src -}}{{- $layout = "plain" -}}{{- $mobile = "" -}}{{- end -}} {{- if not .Params.hero -}}{{- $layout = "" -}}{{- end -}} {{- return (dict "layout" $layout "src" $src "mobile" $mobile "sizes" $sizes) -}}

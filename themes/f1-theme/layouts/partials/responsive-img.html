{{- /* partials/responsive-img.html con srcset w+sizes automatico si existe la variante "_hd" (mismo nombre, sufijo antes de la extension: foto.webp -> foto_hd.webp). Nunca da error si falta la variante _hd -> cae limpio a normal. El ancho para el descriptor "w" se lee del archivo real con images.Config (no hay que declararlo a mano) -- se asume que "_hd" mide exactamente el doble de ancho que el archivo normal, por convencion. Parametros (dict): src -> ruta publica, ej "/images/211-optometria_D3A0068.webp" (obligatorio) alt -> texto alternativo (obligatorio) sizes -> atributo sizes, ej "(min-width:821px) 33vw, 100vw" (opcional; por defecto, el ancho real del archivo en px -> tamano fijo) class -> clase css opcional loading -> "lazy" (defecto) | "eager" */ -}} {{- $src := .src -}} {{- $ext := path.Ext $src -}} {{- $hd := "" -}} {{- $hasHd := false -}} {{- if and $ext (not (strings.HasPrefix $src "http")) -}} {{- $hd = replace $src $ext (printf "_hd%s" $ext) 1 -}} {{- $hasHd = os.FileExists (printf "static%s" $hd) -}} {{- end -}}

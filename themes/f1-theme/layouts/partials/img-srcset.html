{{- /* partials/img-srcset.html Resuelve el srcset w de una imagen local con variante "_hd" (foto.webp -> foto_hd.webp). Devuelve un dict; nunca da error si falta la variante o la imagen es externa. Es la logica que antes vivia dentro de responsive-img.html, extraida para que el hero (picture con source movil) y el preload del calculen lo mismo que el . Cuando el theme pase a escalera de anchos (tarea 4), este es el unico sitio que cambia. Entrada: la ruta publica de la imagen (string), ej "/images/foo.webp". Devuelve dict: src -> la misma ruta hasHd -> bool: existen la base y la _hd hd -> ruta de la _hd ("" si no hay) w -> ancho real de la base en px (0 si no hay _hd) srcset -> "base Nw, hd 2Nw" ("" si no hay _hd) */ -}} {{- $src := . -}} {{- $ext := path.Ext $src -}} {{- $hd := "" -}} {{- $w := 0 -}} {{- $srcset := "" -}} {{- if and $ext (not (strings.HasPrefix $src "http")) -}} {{- $cand := replace $src $ext (printf "_hd%s" $ext) 1 -}} {{/* Hacen falta LOS DOS archivos: el _hd para servirlo, y la base para leer su ancho con images.Config. Comprobar solo el _hd rompía el build durante la transición, cuando el original se renombra a _hd antes de generar la base (images.Config falla con "file does not exist"). */}} {{- if and (os.FileExists (printf "static%s" $cand)) (os.FileExists (printf "static%s" $src)) -}} {{- $hd = $cand -}} {{- $w = (images.Config (printf "static%s" $src)).Width -}} {{- $srcset = printf "%s %dw, %s %dw" $src $w $hd (mul $w 2) -}} {{- end -}} {{- end -}} {{- return (dict "src" $src "hasHd" (ne $hd "") "hd" $hd "w" $w "srcset" $srcset) -}}
